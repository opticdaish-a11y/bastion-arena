# BASTIÓN — Arena Táctica de Héroes

Juego de tablero táctico por turnos (9×9) desarrollado con **React + TypeScript + Vite** y servidor **Node.js + Express + WebSockets**.

## Modos de juego
- **Contra IA**: 3 niveles de dificultad (*Aprendiz*, *Táctico*, *Gran Maestro*).
- **Multijugador Local**: 2 jugadores en la misma pantalla (*Pass & Play*).
- **Multijugador Online**: Salas en tiempo real con código de invitación, lista de salas abiertas y chat en partida.

## Cómo ejecutarlo localmente

```bash
npm install
npm run dev
```

Luego abre `http://localhost:5173` en tu navegador.

## Producción

```bash
npm run build
npm start
```
